# dfa — Deterministic Finite Automaton in Rust

A small, clean implementation of a deterministic finite automaton (DFA) written in Rust.

## Modules

- `machine.rs` — DFA machine core (state transitions)
- `trans_table.rs` — transition table representation
- `identity.rs` — state identity helpers
- `number.rs` — numeric sequence utilities used by tests

## Usage

```bash
cargo run
cargo test
```
